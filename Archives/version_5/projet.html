Projet lié au cours de programmation impérative durant mon premier semestre à l'ENSIIE : Implémentation d'un interpréteur pour un petit langage graphique

L’interpréteur lit sur l’entrée standard un fichier qui a sur sa première ligne un entier représentant la taille de l’image à produire ainsi qu’en deuxième ligne une suite de caractères dont certains représentent des actions à faire. Ces actions permettront en sortie d’avoir une image au format PPM. Voici quelques exemples : Code image 1 Code image 2 Code image 3 Code image 4
